Library Module¶

Core problem definition classes:

  • Problem: Base class for optimization problems

  • Point: Represents a point in parameter space

  • Result: Contains evaluation results

  • BoundingBox: Defines parameter bounds

Problem Wrappers:

  • ProblemWrapper: Base class for composable problem decorators

  • NormalizedProblem: Scales all dimensions to [0, 1]

  • LogTransformProblem: Applies log transform to objective

  • NoisyProblem: Adds controlled Gaussian noise

Library Core¶

This module exposes the core data structures used throughout Panobbgo.

class panobbgo.lib.Result(point: Point | None, fx: float | None, cv_vec: ndarray | None = None, cv_norm: int | float | str | None = None, error: float = 0.0)[source]¶

Bases: object

This represents one result, wich is a mapping of a Point \(x \rightarrow f(x)\).

Additionally, there is also

  • error: estimated or calculated \(\Delta f(x)\).

  • cv_vec: a possibly empty vector listing the constraint violation for each constraint.

Args:

  • cv_vec: the constraint violation vector

  • cv_norm: the norm used to calculate cv. (see numpy.linalg.norm(), default None means 2-norm)

property cv: float¶

Constraint Violation.

The chosen norm of cv_vec; see cv_norm in constructor.

Note

Only the positive entries are used to calculate the norm!

property cv_vec: ndarray | None¶

Vector of constraint violations for each constraint, or None.

Note

Be aware, that entries could be negative. This is useful if you want to know how well a point is satisfied. The .cv property just looks at the positive entries, though.

property error: float¶

Error margin of function evaluation, usually 0.0.

property fx: float | None¶

The function value \(f(x)\) after evaluating it.

property point: Point | None¶

Returns the actual Point object.

property pp: ndarray¶

pareto point, i.e. array([cv, fx])

property who: str¶

The name of the heuristic, who did generate this point (String).

property x: ndarray | None¶

Point \(x\) where this result has been evaluated.

Problem Wrappers¶

Composable decorator classes that wrap a Problem instance and transform inputs/outputs, without modifying the original problem.

These are composable:

wrapped = NormalizedProblem(NoisyProblem(MyProblem()))
