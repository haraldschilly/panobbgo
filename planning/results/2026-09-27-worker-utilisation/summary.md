Files (the raw per-run JSON is not committed; the probe regenerates it in about
a minute per variant):

* `w_base` — master (equivalently `--no-floor`); `w_after` — the shipped
  `popsize_min_workers=True`; `w_rr_*` — the same for `RoundRobin_CMAES`.
* Prototypes (env toggles on a scratch build, not in the PR): `cmaq` λ ≥ q
  with the warm-start fit at the λ ≥ q size; `cmaq_ws` λ ≥ q with the fit at
  the default λ (the shipped variant, except that it did not scale the fit
  with IPOP growth); `cmah` λ ≥ q/2; `cma2` λ ≥ 2q; `cmaq_jsoq` + jSO
  NP_init ≥ q; `cmaq_fill` + filling idle workers from the non-owning arm;
  `fill` the fill alone.
* `d10_*` — d = 10, q 16/64, instance 0 only; `_base` = `--no-floor`.

Columns: busy = busy worker-time / (q · makespan); busy@H = the same over
[0, B/q]; starved / tail = idle worker-time with budget left / after the last
dispatch; mk/ideal = makespan / (B/q); ret/ask = mean candidates returned per
decision point; zero% = share of decision points answered with nothing;
1stfull = mean first time all q workers were busy (runs that got there);
owner_busy = mean busy workers while each arm owned the block.
